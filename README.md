# Kedi İmza Bekleyen Dilekçe Makinesi

## Giriş

Bu proje, insanlık tarihinin en büyük bürokrasi simülasyonudur. Dilekçenizi yazın, sonra kedilerin imza atmasını bekleyin. Bekleyin. Bekleyin. Evren bitene kadar bekleyin.

Kediler çok meşguldür. Birisi tırmalıyor, diğeri uyuyor, üçüncüsü de "bu dilekçe önce çay demlensin" diyor. Gerçek hayattaki gibi.

## Nasıl Çalışır?

1. Programı çalıştırın.
2. Dilekçenizi yazın.
3. Kedilerin onayını bekleyin.
4. Sonsuza kadar bekleyin.
5. Hayatınızı sorgulayın.

Bu makine, bilimsel olarak kanıtlanmış yavaşlığıyla ünlüdür. Her imza için ortalama 3.14 kedilik bir mola alınır.
